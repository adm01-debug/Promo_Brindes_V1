# Anexo — revisão das 230 referências de produto

Base: `11f0d35`, 23/09/2026. Leia primeiro o [parecer e evidências](REVISAO_PLANOS_20260923.md).

Este anexo mantém uma linha para cada ID da matriz. “Registrado” é o estado documental anterior; “Revisão” é uma proposta de leitura, não alteração do CSV nem certificação integral.

- **I:** entrega técnica identificada; não substitui aceites humanos quando explícitos.
- **P:** parcial, defeito ou aceite ainda não demonstrado.
- **N:** entrega não localizada.
- **E:** depende de material, pesquisa ou decisão externa.
- **Δ:** revisão específica nesta rodada, por fonte atual ou simulação identificada.
- **Base:** conclusão herdada e rastreada documentalmente; não houve novo teste individual para essa linha. Sua formulação histórica não deve ser tratada como nova observação de produção.

A referência pode conter mais de um critério; por isso uma entrega técnica antes I pode ficar P no aceite integral. Não somar os rótulos para calcular percentual de prontidão. As decisões arquiteturais GR14/24/26/30 são alternativas registradas, não omissões a implementar automaticamente.
